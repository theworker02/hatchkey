# hatchkey

Hatch HTML/Markdown key fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/hatchkey/

## Install / run

```bash
git clone https://github.com/theworker02/hatchkey.git
cd hatchkey
node src/cli.js
node --test
```
